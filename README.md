# 基于年报文本挖掘的上市公司数字化转型测度及其绩效影响研究

> ——来自沪深A股上市公司的经验证据

一个零依赖的**单文件**论文项目展示页，由 GitHub Pages 托管。将毕业论文组织为可直接阅读、可打印、可分享的在线版本。

## 在线访问

部署地址见仓库 About 区，或直接打开：`https://<你的用户名>.github.io/<仓库名>/`

## 论文概要

| 项目 | 内容 |
| --- | --- |
| 样本 | 2019—2023 年沪深 A 股 428 家上市公司 |
| 观测值 | 2140 个企业—年度非平衡面板数据 |
| 数据来源 | 巨潮资讯网年报全文 + 国泰安 CSMAR |
| 核心方法 | 「种子词典 + Word2Vec 相似词扩充」构建数字化转型词典（127 → 215 词） |
| 测度 | 数字化转型指数 DTI = 词典词频合计 / MD&A 总词数 × 100 |
| 测度质量 | Cronbach's α = 0.87，分半信度 0.83，收敛效度通过 |
| 核心结论 | DTI 每提高 1 个标准差，ROA 平均提升约 0.21 个百分点 |
| 异质性 | 国有企业（0.158）> 非国有企业（0.097）；高技术行业（0.171）> 非高技术行业（0.089） |

## 研究流程：五步流水线

```
数据获取 → 文本预处理 → 测度构建 → 信效度检验 → 回归分析
```

每一环节的输出均为下一环节的输入，保证「测度先验证、后使用」，避免未经检验的指标直接进入因果推断环节。
